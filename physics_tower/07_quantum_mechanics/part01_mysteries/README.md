# part01 古典像が破綻する実験

量子力学の公理を先に暗記せず、「古典論なら何を予測し、実験は何を否定したか」を追います。

| 記事 | 破れた古典的前提 | 必要になった概念 |
|---|---|---|
| [放射・光子](01_radiation_quanta_and_photons.md) | energy交換は連続、光は波だけ | energy量子、photon |
| [原子・物質波](02_atomic_spectra_and_matter_waves.md) | 安定軌道と連続振動数 | 離散準位、物質波 |
| [干渉・spin](03_single_particle_interference_and_spin.md) | 粒子は経路を持ち、測定は読むだけ | 確率振幅、非可換測定 |
