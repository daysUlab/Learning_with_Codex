# part01 歴史的実験を現代量子論で読み直す

量子力学の公理を先に暗記せず、「古典論なら何を予測し、実験は何を否定したか」を追います。その後、density operator・POVM・quantum channel・量子場を知る現代から同じ実験を読み直します。歴史上の科学者が後世の概念を持っていたかのようには書きません。

| 記事 | 破れた古典的前提 | 必要になった概念 |
|---|---|---|
| [放射・光子](01_radiation_quanta_and_photons.md) | energy交換は連続、光は波だけ | energy量子、photon |
| [原子・物質波](02_atomic_spectra_and_matter_waves.md) | 安定軌道と連続振動数 | 離散準位、物質波 |
| [干渉・spin](03_single_particle_interference_and_spin.md) | 粒子は経路を持ち、測定は読むだけ | 確率振幅、非可換測定 |
| [Bell・CHSH](04_bell_chsh_experiments.md) | 局所的な既定値で全相関を説明できる | entanglement、setting依存の相関 |

歴史順は発見の道筋ですが、現代理論の論理順と同じではありません。Bohr模型や光子像も適用範囲を持つ中間modelとして扱います。
