# 量子力学の数学診断室

一般数学を最初からやり直す場所ではありません。「どの式で止まったか」から必要な操作へ戻ります。

| 止まった式・操作 | 戻る節 |
|---|---|
| $$|\alpha|^2,\ e^{i\theta},\ \psi^*$$ | [複素数・位相](01_quantum_math_diagnostic.md#複素数と位相) |
| $$\hat A|\psi\rangle=a|\psi\rangle$$ | [固有値・Hermitian](01_quantum_math_diagnostic.md#固有値とhermitian) |
| $$\int|\psi|^2dx=1$$ | [積分・確率](01_quantum_math_diagnostic.md#確率と規格化) |
| $$[\hat x,\hat p]=i\hbar$$ | [commutator](01_quantum_math_diagnostic.md#commutator) |
| $$\phi(p)=\mathcal F[\psi]$$ | [Fourier変換](01_quantum_math_diagnostic.md#fourier変換) |
| $$|\psi\rangle\otimes|\phi\rangle$$ | [tensor product](01_quantum_math_diagnostic.md#tensor-product) |
| $$i\hbar\partial_t\psi=\hat H\psi$$ | [微分方程式・境界条件](01_quantum_math_diagnostic.md#微分方程式と境界条件) |

既存正本も参照してください：[線形代数](../../00_physics_math_tools/linear_algebra/README.md)、[微分方程式](../../00_physics_math_tools/differential_equations/README.md)、[複素解析](../../00_physics_math_tools/complex_analysis/README.md)、[実験誤差](../../00_physics_math_tools/experiment/errors_significant_digits.md)。
