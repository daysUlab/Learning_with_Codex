# part05 有限自由度から場へ

[粒子から連続体・場へ](01_from_particles_to_fields.md)で、座標の添字を空間点へ拡張し、Lagrangian密度、field equation、境界項、Noether currentの入口を扱います。

弦の横変位を例に導出します。電磁場や量子場の詳論は後章へ残し、「同じ変分構造が残る」ことを確認します。
