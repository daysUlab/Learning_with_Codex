# part01 座標と表現を選び直す

Newton力学の結果を保持したまま、Cartesian成分と拘束力を追う記述から、自由度に合う一般化座標へ移ります。

- 残す：可能なconfiguration、質量、相互作用、初期条件。
- 省略する：拘束で独立に動けない座標、不要な拘束力。
- 導入する：自由度、一般化座標、configuration space。
