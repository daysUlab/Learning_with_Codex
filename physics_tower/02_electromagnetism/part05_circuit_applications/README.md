# part05_circuit_applications――大学受験から工学初歩へ

## 三つの層

1. **大学受験物理**：直列・並列、測定回路、コンデンサ切替、電磁誘導を、成立条件つきで解く。
2. **工学部初年級**：RC・RL・RLC、フェーザ、交流電力、変圧器を微分方程式と端子モデルで扱う。
3. **高周波・電力・電気機器への入口**：モーター、発電機、伝送線路、アンテナで集中定数の外側を見る。
