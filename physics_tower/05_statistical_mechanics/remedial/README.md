## ミニ診断

1. 二枚のcoinのmicrostateを四つ書けるか。
2. 分布の期待値と最頻値が違い得ると説明できるか。
3. 全確率が一になるよう正規化できるか。
4. 固定される量からensembleを選べるか。
5. 電子にMaxwell–Boltzmann分布を無条件で使えない理由を言えるか。

三つ以上「いいえ」なら、該当層の記事から戻ってください。
