# 教科書設計

## 目的
前編は数式を使わず宇宙の成果を理解し、後編は高校数学III・Cから数学と物理を積み上げて再訪する。前編26章・後編31章、156候補を暫定採用する。二巻それぞれQuarto HTML/PDFとし、章番号は通し番号で参照する。

## 前編の節構造
問い → 観測／予言の具体例 → 図表とスケール比較 → どう分かったか → 何が未解決か → 後編の参照章。数式・数式記号による導出は禁止（数値・単位・表・グラフは可）。写真、観測再構成画像、数値計算、模式図、想像図をキャプションで区別する。章末は思考実験と短い理解度確認・解答。歴史的発見を現代の理論と混同しない。

## 後編の節構造
従来法の限界 → 高校数学からの橋渡し → 定義と物理的入力 → 途中式 → 数値例 → 単位・符号・極限の検算 → 観測との照合 → 適用限界 → 演習と解答。場の量子論等への参照は補助で、本線の必要前提は本文で導入する。一般相対論の方程式は物理的入力として扱い、解・測地線・予測を導出。ホーキング放射の厳密導出、非線形数値相対論、量子重力は発展扱い。

## 根拠管理
A: 観測結果、B: 観測で支持される理論的理解、C: 観測された現象の本質が未解明、D: 理論上の予言・仮説。複数区分が混在するテーマは主張単位で区別する。文献日・確認日・観測量・推定モデル・不確実性を記録する。最新値は固定せず版の日付を明記。

## 図版
白背景、日本語、文字を大きく、注釈は要点に限定。グラフの軸・単位・尺度を記載する。自作図のソースを保存し、外部画像は個別ライセンス・クレジットを確認してから採用する。生成画像を観測画像として使わない。HTMLとPDFで視認性を検査する。

外部画像は [図版台帳](research/image_registry.md) に出典・配布URL・公開日・全クレジット・ライセンス・変更有無・確認日を記録する。図の近くにも全クレジットと出典・ライセンスを掲載し、観測画像と模式図を明示する。公式画像を事前取得してHTML/PDF共通のローカル資産として利用する。検索サムネイルは転載しない。
