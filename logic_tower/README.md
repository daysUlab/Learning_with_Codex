# logic_tower

logic_tower の入口ページです。
このタワーは、**「論理式を読むのが初めて」**という段階から、
命題論理・述語論理・健全性/完全性・計算可能性・非古典論理までを、
段階的に学ぶための教科書シリーズです。

physics_tower と同様に、単語の定義だけで終わらず、
**直観 → 定義 → 例 → つまずきやすい点 → 確認**の順で理解を積み上げます。


## このタワーを貫く問い

Logic Towerは、論理体系を順番に覚えるだけでなく、**なぜその論理を使うのか、どこまで表現できるのか、現代科学・計算機・AIにどう残っているのか**を追います。

中心となる問いは、「なぜ、より表現力の高い論理があるのに、命題論理や一階述語論理を使い続けるのか」です。答えを、次の4軸のトレードオフとして検討します。

- 表現力：何を直接書けるか
- 推論可能性：どの結論を規則から導けるか
- 計算可能性：機械的に何を判定・探索できるか
- 実用性：どの抽象化が問題を見通しよくするか

## 3. まず最初に覚える用語（最小セット）
- **命題（proposition）**: 真か偽かが定まる文。
- **論理式（formula）**: 記号で書いた命題。
- **解釈（interpretation）**: 記号に意味を与えるルール。
- **モデル（model）**: ある論理式を真にする解釈。
- **証明（proof）**: 推論規則に従って結論へ到達する手続き。
- **妥当（valid）**: どの解釈でも常に真になる性質。

この6語を混同しないだけで、論理学の難しさはかなり減ります。

---

## 4. 典型例（超短い導入）
次の主張を考えます。

- 「雨が降るなら地面は濡れる」
- 「雨が降る」
- したがって「地面は濡れる」

これは命題論理では次の形です。

- `P -> Q`
- `P`
- `Q`

この推論は **modus ponens** と呼ばれ、
論理学で最初に身につける基本規則です。

---

## 5. つまずきやすい点
- 記号の意味を覚える前に、式変形だけを追ってしまう。
- 「証明可能」と「真である（意味的に正しい）」を混同する。
- 量化記号のスコープ（どこまで効いているか）を見落とす。
- 否定の位置（`¬(A ∨ B)` と `¬A ∨ B`）を取り違える。

迷ったら、
1) 日本語に戻す、2) 何を仮定しているかを書く、3) スコープに括弧を付ける、
の3手順で復帰できます。

---

## 6. 学習チェック（自己確認）
- 「妥当」と「証明可能」の違いを1〜2文で説明できる。
- `P -> Q, P ⊢ Q` がなぜ成立するかを真理値表または規則で示せる。
- `∀x P(x)` と `∃x P(x)` を日本語と往復できる。
- 1つの主張について、証明的な見方とモデル的な見方を両方で述べられる。

## ページラベルと確かさの表示

本文化したページでは、種別・前提・難易度・読了目安を表示します。現代研究やAIを扱う記事では、次も区別します。

- 定理：明示した形式体系の下で証明された内容
- 実証結果：論文・実験・ベンチマークで確認された内容
- 解釈：事実や結果を理解するための説明
- 仮説：今後の検証が必要な考え

自然言語例は直観と形式化の選択を学ぶため、数学例は量化・反例・証人・証明を明確に学ぶために併用します。
