# 論理の粒度・表現力・限界

自然言語を命題として切り出す段階から、一階論理と高階論理のトレードオフまでを扱います。

> 種別：発展・応用  
> 状態：全11記事 本文化済み  
> 前提：なし〜一階述語論理

## このカテゴリの役割

本線で学んだ論理体系を、個別テーマの列挙ではなく、**表現力・推論可能性・計算可能性・実用性**のトレードオフとして読み直します。全11記事を本文化済みです。各記事は単独でも読めますが、表の順に読むと自然言語の粒度から一階論理の位置付けまで段階的につながります。
