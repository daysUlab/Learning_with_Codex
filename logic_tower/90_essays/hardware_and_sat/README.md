# Boolean代数・回路・SAT

命題論理から論理ゲート、回路検証、SATソルバーへ接続します。

> 種別：発展・応用  
> 状態：全8記事 本文化済み  
> 前提：命題論理

## このカテゴリの役割

本線で学んだ命題論理を、**Boolean代数 → ゲート → 回路 → SAT・BDD**へ接続します。全8記事を本文化済みです。表現可能性と、回路サイズ・深さ・検証範囲など実装上の条件を分けて読める構成です。
