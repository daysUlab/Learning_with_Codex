# 様相論理の一階論理への標準翻訳

> 種別：発展・応用  
> 状態：本文化済み  
> 前提：述語論理・様相論理  
> 難易度：基礎〜発展  
> 想定読了時間：24分

Kripke意味論の世界を一階論理の個体、到達可能性を二項関係として扱うと、様相式を一階論理式へ再帰的に翻訳できます。翻訳は現在世界を表す自由変数に相対的です。

---

## 1. このページの到達目標

- BoxとDiamondを標準翻訳する
- 世界変数と到達可能関係を読む
- 翻訳の範囲を説明する

---

## 2. 全体像

この図では、「前提を固定する → 中心概念を形式化する → 具体例で検算する → 保証範囲を確認する」という流れを読み取ります。

```mermaid
flowchart LR
    A["前提を固定"] --> B["命題変数の持ち上げ"]
    B --> C["必然と可能"]
    C --> D["保証範囲を確認"]
```

式を操作する前に、対象・意味論・評価範囲を固定します。同じ記号でも、採用したモデルが違えば保証内容も変わります。

---

## 3. 基本事項

### 1. 命題変数の持ち上げ

様相命題 $P$ は世界により真偽が変わるため、一階論理では単項述語 $P(x)$ として表します。

### 2. 必然と可能

$\Box A$ は到達可能な全世界で $A$、$\Diamond A$ は到達可能なある世界で $A$ と翻訳します。

### 3. 再帰的翻訳

論理結合子は保ち、内側の式を到達先世界へ相対化します。結果は二項関係 $R$ と命題述語を持つ一階論理の断片です。

---

## 4. 段階例

$\Diamond\Box P$ は、到達可能なある世界 $y$ があり、そこから到達可能なすべての $z$ で $P(z)$ が成り立つ、と翻訳されます。

中心となる式は次です。

$$
ST_x(\Box A)=\forall y\,(R(x,y)\to ST_y(A))
$$

1. 式に現れる対象・変数・演算の意味を固定します。
2. 各部分式が要求する内容を日本語へ戻します。
3. 最小の具体例または反例で境界条件を調べます。
4. 結論が、採用したモデルと探索範囲を越えていないか確認します。

## 5. 四つの軸から見る

| 軸 | このページでの見方 |
|---|---|
| 表現力 | どの区別や性質を直接表せるか |
| 推論可能性 | 規則・定義・同値変形から何を導けるか |
| 計算可能性 | 有限手続きで判定・探索できる範囲はどこか |
| 実用性 | 必要な情報を保ちながら、レビュー・実装しやすいか |

表現を増やせば常に良くなるわけではありません。必要な区別を保ち、検証できる粒度を選びます。

## 6. つまずきやすい点

### 1. Boxは全個体量化

全世界ではなく、現在世界から到達可能な世界を量化します。

### 2. 自由変数xを消す

翻訳はどの世界で評価するかに相対的です。

### 3. 翻訳できるから同じ言語

表面構文、自然な不変性、決定手続きは異なります。

### 復帰手順

1. 何を個体・状態・値としているか一行で書きます。
2. 量化・否定・演算のスコープへ括弧を付けます。
3. 成立例だけでなく、最小の反例候補も試します。
4. 「証明済み」「モデル内で確認」「経験的に支持」「解釈」を区別します。
5. 元の自然言語要求と形式化を再照合します。
