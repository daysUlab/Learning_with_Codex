## 執筆時の共通方針

- 直観 → 定義 → 例 → 誤解・復帰方法 → 演習 → 全解答 → 学習チェックの順を基本とする。
- ページ冒頭に種別・前提・難易度・読了目安を表示する。
- 確立事項、実証結果、解釈、仮説を区別する。
- 既存の完成記事と重複する場合は、正本へリンクして発展部分に集中する。
