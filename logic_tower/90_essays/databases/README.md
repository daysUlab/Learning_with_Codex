# 論理とデータベース設計

問い合わせだけでなく、関数従属性・キー・正規化・無損失分解を形式的推論として扱います。

> 種別：発展・応用  
> 状態：全13記事 本文化済み  
> 前提：集合・関係・述語論理

## このカテゴリの役割

本線で学んだ集合・関係・述語論理を、問い合わせとデータベース設計へ接続します。全13記事を本文化済みで、関係モデルから関数従属性、正規化、無損失結合、依存性保存、SQLの実装差まで順に読めます。

## 各記事の共通構成

- 直観 → 定義 → 例 → 誤解・復帰方法 → 演習 → 全解答 → 学習チェックの順を基本とする。
- ページ冒頭に種別・前提・難易度・読了目安を表示する。
- 確立事項、実証結果、解釈、仮説を区別する。
- 既存の完成記事と重複する場合は、正本へリンクして発展部分に集中する。
